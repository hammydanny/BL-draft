V0.6.9.6

MOBILE OVERHAUL / 0.6 FINAL

16 October 2026

  • The Auction share report now traps keyboard focus, closes with Escape, restores focus to its trigger and locks background scrolling without changing the shared lineup.
  • The no-scroll Primary Directory now fits short landscape screens up to 1200px wide, including 932px phones, with 44px navigation targets.
  • Mobile Database dropdowns now use the shared localized UI font, and refreshed Japanese, Chinese and Korean font subsets include every current translated UI glyph.
  • Localization coverage now distinguishes technical viewport metadata from descriptive content and checks every text segment in compound labels; regression fixtures protect both rules.
  • Updated mobile, Database and localization assets use fresh cache URLs while preserving the existing image and font service-worker cache.
  • Verified canon quote source text remains exact in the reference data, while dossier quotes now translate into the selected interface language. Browser tab titles keep “Blue Lock Draft” unchanged and translate only the page-specific title.
  • Locked secret dossiers remain protected when opened by direct URL.
  • Phase 4 adapts Characters and Chemistry for phones and tablets with compact search and sort controls, filter sheets, readable cards, exact pair checking and a comparison sheet for up to three players.
  • Mobile dossiers gain compact identity panels, sticky section navigation, readable radar and stats, and stacked positions, weapons, chemistry and history. Database return state, cached cards, shared portrait loading and desktop layouts are preserved.
  • Tapping an empty pitch position now opens the active team’s Reserve Picker on both desktop and mobile, with positional fit labels. Desktop uses a compact centered dialog with aligned player identity, position badges, OVR and fit status for cleaner scanning; choosing a reserve still uses existing placement logic and selected-player placement takes priority.
  • Phase 3 adapts both Team Builders for touch: select a player, see position fits, then tap to move or swap. Compact pitch markers keep names, OVR and Captain badges readable without changing formation coordinates.
  • Mobile formation controls, selected-player and Captain actions, expandable Reserves and Chemistry, and a scrolling standalone Player Pool sheet keep the pitch central. Pool search, filters, presets and selection state use the existing system.
  • Tablet and landscape workspaces, translated accessible controls, stable selection and pool scrolling, and an explicit touch drag handle improve mobile use while preserving desktop dragging, Auto Best, exact sharing and saved squads.
  • Compact mobile header and flat navigation drawer with shared theme, sound and language settings.
  • Touch-friendly spacing, safe-area support, keyboard-aware dialogs and responsive typography.
  • Phase 2 rebuilt the Auction for phones and tablets with compact team trackers, a sticky bid dock, touch-friendly bidding, keyboard-safe custom bids, mobile history and responsive portrait, landscape and tablet layouts.
  • Coin flip, GOES FIRST, player reveal, SOLD / ASSIGNED and special Auction states were adapted for mobile without changing Auction rules, budgets, roster limits or Undo / Redo.
  • The header now uses a higher-quality logo source for crisper desktop and high-DPI mobile rendering.
  • Auction player cards now show nationality flags, while secret characters remain hidden unless legitimately unlocked and protected session restores prevent accidental exposure.
  • The mobile three-bars directory now uses a compact no-scroll layout that keeps the full menu visible while the background remains locked.
  • The desktop Settings gear now acts as a true toggle: click once to open Settings and click it again to close; X, backdrop and Escape still work.
  • The Changelog release-history sidebar now keeps subversions hidden inside click-to-open version groups, uses a small + / − expansion indicator, and animates each group open/closed.
  • Opening Settings now keeps the document scrollbar gutter reserved while background scrolling is locked, preventing the page from shifting sideways when the gear panel opens or closes.
  • Localization is now a mandatory release gate: every new or changed visible UI string, accessibility label and Changelog note must ship in all supported languages before an update is considered complete.
  • A site-wide localization audit closed remaining Changelog, page metadata and dynamic UI gaps, and added automated source-coverage checks for future updates.

V0.6.7

AUCTION CPU / STRATEGIC BIDDING

17 October 2026

  • Team 2 CPU control is optional in Auction Setup; leaving it off preserves the existing human-versus-human auction.
  • For each auction target, the CPU weighs player OVR and position coverage across goalkeeper, defence, midfield and attack.
  • The CPU checks chemistry with Team 2's current roster, favouring promising links and scoring down poor fits.
  • Its bid ceiling reflects remaining cash and open roster slots, reserving money for future signings instead of spending the whole budget on one character.
  • The CPU automatically submits an opening bid, responds to human bids or passes when the asking price exceeds its valuation.
  • CPU bidding follows the configured bid interval and respects existing budget, roster-capacity, save/resume and undo/redo rules.
