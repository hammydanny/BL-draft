THE PROGRAM EVOLVES

Release notes, without the noise.

Website and game milestones from the project's documented history.

MOBILE OVERHAUL // PHASES 1–2

15 October 2026

  • Built the mobile foundation with a compact header, touch-first directory, safe-area support, responsive typography, keyboard-aware dialogs, reduced-motion handling and RTL-aware layouts.
  • Reworked the Auction for phones and tablets with compact expandable team trackers, mobile player evaluation, sticky bidding controls, touch-friendly quick bids and keyboard-safe custom bid entry.
  • Upgraded the coin flip, GOES FIRST result, player reveal, SOLD / ASSIGNED states and Auction History for portrait, landscape and tablet play while preserving existing Auction rules and Undo / Redo behaviour.
  • Added higher-quality header branding and improved Auction presentation details, including nationality visibility and protected secret-character resume behaviour.
  • Follow-up mobile polish removed scrolling from the three-bars directory and compacts its navigation to keep the full menu visible without moving the page behind it.
  • Settings can now be closed by pressing the desktop gear again, while the existing X, backdrop and keyboard controls continue to work.
  • The Changelog is now grouped into collapsible release families so older 0.6.x and 0.5 history no longer fills the page by default.

V0.6.8.3 ALPHA

RESPONSIVE TACTICAL POLISH

A focused display-scaling and Team Builder readability pass.

  • Removed the redundant fan-project strip above the footer on the Homepage.
  • Large desktop shells and the shared header now scale more naturally with higher-resolution monitors.
  • Team Builder pitches are slightly taller to separate player names, position labels and fit markers.
  • Light Mode uses a more visible background emblem, clearer chemistry-link colors and stronger, distinct SWAP / BEST FIT / GOOD FIT states.
  • Clicked pitch players now receive a clearer dedicated selection ring without interfering with drag-target feedback.

V0.6.8.2 ALPHA

UX & RELIABILITY

A practical Scouting Desk, reliable portraits and clearer tactical feedback.

  • Search real players and check any chemistry pair directly from the Homepage.
  • Central portrait loading prioritizes visible cards, handles rapid selection safely and bounds retries.
  • Team Builder preserves selection scroll and distinguishes blue SWAP targets from gold BEST FIT and green GOOD FIT targets.
  • Larger Results portraits and readable position / Captain badges retain the compact two-team report.
  • Light Mode uses coherent tactical surfaces, chemistry colors and player controls.

V0.6.8.1 ALPHA

WEBSITE POLISH

A focused v0.6.8.1 polish pass on the Homepage, Team Builder, Auction flow and Light Mode.

  • Removed the Homepage system-status strip and cleaned up the header SFX control.
  • Moved Captain controls above Core Attributes and removed the redundant field-metrics sublabel.
  • Auction player advances preserve the current scroll position instead of jumping to the top.
  • Light Mode now has coherent tactical pitches, calmer scrollbars, cleaner chemistry/link colors and fewer dark-theme leftovers.
  • Retains the v0.6.8 Homepage discovery, information pages, footer and website-experience overhaul.
