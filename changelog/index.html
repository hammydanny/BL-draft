THE PROGRAM EVOLVES

Release notes, without the noise.

Website and game milestones from the project's documented history.

LATEST // WEBSITE EXPERIENCE

A focused v0.6.8.1 polish pass on the Homepage, Team Builder, Auction flow and Light Mode.

  • Removed the Homepage system-status strip and cleaned up the header SFX control.
  • Moved Captain controls above Core Attributes and removed the redundant field-metrics sublabel.
  • Auction player advances preserve the current scroll position instead of jumping to the top.
  • Light Mode now has coherent tactical pitches, calmer scrollbars, cleaner chemistry/link colors and fewer dark-theme leftovers.
  • Retains the v0.6.8 Homepage discovery, information pages, footer and website-experience overhaul.

V0.6.7.4 ALPHA

STABILIZATION

Resolved conflicting document imports and stabilized the website foundation.

  • Removed merge artifacts and duplicate assets; repaired favicon placement.
  • Centered Auction navigation and preserved dedicated character links on reload.
  • Moved Auction player OVR into Attribute Analysis and enlarged its portrait within the existing panel.
  • Fixed clipping and overlaps in compact share reports.

V0.6.7.x

WEBSITE FOUNDATION

Established the multi-page website shell around the existing game.

  • Shared navigation, contextual headers, browser-history routing and page-transition guards.
  • Dark / Light / System preferences, Settings, global SFX and Quick Draft access.
  • Readable player evaluations, consistent local fonts and bounded portrait loading.

V0.6

PLAYER EVALUATION

The v0.6 series developed the player-stat presentation, lineup optimization and maintenance foundation.

  • Six-axis field-attribute radar, numerical values and supplementary letter grades, with GK shown separately.
  • Auto Best evaluates all ten formations; shared reports preserve the chosen lineup.
  • Later v0.6 updates documented an expanded player database, image-loading improvements and save compatibility work.

V0.5 ALPHA

EARLY SQUAD EXPERIENCE

The recorded V0.5 snapshot already included Auction drafting, player-pool selection, formation building, chemistry and a standalone Team Builder.

Older milestones are summarized from repository snapshots and existing notes. Exact release dates and undocumented changes are intentionally omitted.
