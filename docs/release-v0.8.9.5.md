# v0.8.9.5 — Isagi Flow and Rainbow Presentation

- Yoichi Isagi gains **Metavision: Puzzle Completion**, a dedicated Flow ability that improves tactical awareness, anticipation, space recognition and spotting passing runs. Two-Gun Volley stays a separate Flow-dependent ultimate.
- Active Flow makes the side formation's horizontal Flow meter, stamina ring, stamina bar and live rating/OVR text rainbow; inactive Flow remains blue.
- Flow kit cards and references use rainbow borders and accents instead of pink.
- Isagi's new name, ability description and match label are translated in all 11 supported languages.
- No changes to secret character records, ratings or chemistry.
