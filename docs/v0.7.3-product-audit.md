# v0.7.3 product audit

Written before the v0.7.3 implementation, against `main` at `fe0e520` (v0.7.2.3,
supported cutoff Chapter 364, 79 public players and 10 secret characters derived from
`players` / `secretCharacter`). It describes what was actually found in the code and in
a local Chromium pass (1440×900 and 390×844, dark theme, English).

## Current strengths

- **One football model.** Effective OVR, position profiles (primary / secondary /
  adapted / poor), the bounded chemistry curve, Auto Best and CPU planning all live in
  `squad-balance.js`, `chemistry.js`, `formations.js` and `auction.js`. Daily and the
  puzzle missions already evaluate squads through `shareFormationSnapshot`, so modes
  agree about squad quality.
- **Deterministic, validated content.** Daily offers are seeded and replayable from an
  action list; squad and challenge codes are checksummed and strictly validated; save
  migrations are versioned with fixtures (`scripts/fixtures`).
- **VS CPU is genuinely strategic.** Difficulty changes decision quality, not resources,
  and the v0.7.2.3 paired experiment proves the ordering.
- **Daily Ego Draft has a good core loop** — three offers, Ego Token rerolls, formation
  choice, live pick impact and a transparent score breakdown.
- **Separate storage keys** for Auction, Builder, Daily/puzzles, mode records and the
  squad library; corrupt data is rejected rather than trusted.
- **Localization architecture** (English source keys, catalog + runtime text-node
  translation, coverage scanner) is solid and enforced by preflight.

## Current weaknesses

- **Daily days are mechanically the same day.** Ten themes change weights and the
  objective counter, but every day is "pick 1 of 3, size 7–14, 2 tokens, score =
  quality + chemistry + objective + fit". "Speed Kills" and "Technicians" play
  identically: the optimal policy is "take the best fitting player".
- **The ten curated challenges are a flat list.** No categories, no filter, no
  medal/grade progress, no explanation of what makes a mission hard; once completed
  there is no reason to return.
- **No head-to-head drafting without an auction.** VS CPU needs a 15–25 minute auction.
  There is no quick competitive mode that uses the drafting skills Daily teaches.
- **Challenge sharing is half-built.** `BLDC1/BLDC2` codes exist for auction scenarios,
  but there is no way to *author* a challenge, and the import button is hidden inside
  the "More info" disclosure of the puzzle hub.
- **Records are scattered and mostly invisible.** `bldSoloRecordsV1` (Daily / puzzles)
  and `bldModeRecordsV2` (auction missions) are only visible inside individual dialogs.
  Nothing summarizes what a player has achieved.

## Retention problems

1. **Nothing changes tomorrow except a title.** The theme name changes; the decision
   space does not.
2. **One daily activity.** After one Daily run (~4 minutes) the site has no other
  "today" content. There is no "what can I do today?" screen.
3. **No visible history.** The 7-day list is collapsed inside the Daily briefing.
4. **Completed missions are dead ends.** No medals, no optional-goal tracking across
   attempts, no "next mission" suggestion.
5. **No social loop.** A player cannot send a friend "beat this".

None of these should be solved with streak punishment, energy or currencies; the
fix is more varied, better-presented content and real records.

## Gameplay problems

- Daily objectives are a single counter folded into the score; the "objective" rarely
  changes which player is picked.
- The superstar theme (`king`) is the only theme that changes offer rules.
- Rerolls are always two; scouting depth never varies.
- Puzzle missions always fix the captain and require 11/11 natural fit — good — but the
  only budget lever is fixed prices; there are no partially broken squads beyond
  "Fix the Team".
- No mode uses denial or scarcity (taking a player so the opponent cannot).

## UX problems

- Header "CHALLENGES" opens a modal that opens another modal. The home "Play" cards
  open modals too; there is no persistent hub screen with progress.
- The Daily briefing shows an empty "BEST TODAY" with a large bare dash bar.
- Puzzle hub on a phone is a single very long list (10 tall cards) with no filter.
- "IMPORT CHALLENGE" is buried; "SAVED SQUADS / IMPORT SQUAD" float under the mode grid
  without a heading.
- Battle Sim's home card sits alone in a half-empty row on desktop.

## Visual problems found

- **Mobile home utility cards break words**: "DATABAS / E" wraps mid-word in the
  two-column Team Builder / Database cards at 390 px; card text is centred while
  every other card is left aligned.
- **Daily card overline wraps** ("DAILY EGO DRAFT · 2026- / 11-02") at 390 px.
- **Empty best-score state** renders an oversized dash glyph.
- **Header shell drift**: six game documents still contained a "Meet the developers"
  block that the live home page had dropped (dead markup, duplicate `#menuAbout`).

## Technical debt

- **Broken release gate on `main`.** `js/preflight.js` had a syntax error (a collaborator
  patch spliced two checks into the middle of a string), and 13 further checks were
  failing behind it: null secret-character reference modules registered as profiles,
  14 untranslated secret-character weapon strings, an untranslated Battle Sim line,
  stale test expectations for collaborator-updated secret data, and redirect stubs that
  the shell checks did not recognise. Eight of these already failed at `443da13`.
- **Real secret leak.** Since secret chemistry moved into the shared table, public
  dossiers (e.g. Shoei Baro) listed Qazicutie's pair card in locked sessions.
- **Fifteen near-identical 48 KB page shells.** Seven legacy `*.html` copies and seven
  canonical directory copies of `index.html` must be edited by hand. They had drifted:
  `auction/results/` still requested `chemistry.js?v=0.7.10.0` and
  `player-reference.js?v=0.7.2.3` while other pages requested newer files, so a player
  on Results could run stale chemistry code.
- **Three version schemes** (`0.7.2.3`, `0.7.10.x`, `0.7.2.10`) for cache busting.
- Two generations of challenge engines (auction "modes" v0.7.1 and solo puzzles
  v0.7.2.1) with separate record stores.

## Proposed v0.7.3 direction

1. **Restore and harden the release gate** first; fix the secret leak; make
   `index.html` the single editable shell (`scripts/sync-shells.js`), turn legacy
   `*.html` URLs into tiny redirects, and move every cache-busting reference with one
   command (`scripts/set-version.js`). Preflight fails on drift.
2. **Daily Ego Draft v3: daily rules.** Each date gets one validated *mechanical* rule
   on top of its theme (e.g. Deep Scouting = four offers and no rerolls; Salary Cap =
   priced offers and a budget; Locked Captain = start with a fixed player; Elite Cap;
   Natural Roles scoring; Formation Lock; Chemistry Scoring). Rules are chosen from a
   compatibility table, never repeat on consecutive days, and are tested over 365 dates.
3. **Ego Board** — one "Today" screen: Daily Ego Draft, Daily Tactical Challenge and
   Daily Draft Duel, each with status, grade and best score, plus a 7-day strip that
   never punishes gaps.
4. **Daily Tactical Challenge** — a 2–5 minute squad puzzle generated from validated
   templates (Final Pieces, Budget Crunch, Repair Job, National Duty). Every generated
   puzzle carries a solver witness, so it is solvable by construction and tested.
5. **Ego Draft Duel** — a quick competitive draft against a CPU manager with a shared
   market of four: alternate first pick, the opponent takes one of the rest, the
   remainder vanishes. Denial, scarcity and timing matter. Formats Quick 7 / Standard
   9 / Full 11; Easy / Normal / Hard differ by evaluation quality only and never see
   future markets. The result is a transparent draft verdict (Effective OVR, Base
   Quality, chemistry, fit), not a match simulation.
6. **Challenge Lab** — an approachable creator for squad puzzles (formation, budget,
   pool, max OVR, banned players, locked starters, captain, objectives) with a
   feasibility solver and validated `BLDL1` codes for "beat this" sharing.
7. **Draft Challenges browser** — categories and difficulty filters, medals derived
   from grades, optional-goal display, and new curated missions only where they add a
   new decision.
8. **Ego Record + achievements** — a local profile built only from reliably recorded
   results (with migration from existing Daily/puzzle records) and a short list of
   achievements that represent real accomplishments.
9. **Navigation** — header "PLAY" (Auction, Quick Draft, VS CPU, Draft Duel) and
   "CHALLENGES" (Ego Board, Daily Ego Draft, Draft Challenges, Challenge Lab, Ego
   Record) groups; the home page leads with today's board.

## Explicitly out of scope

- Battle Sim engine, balance, AI, Match Gauntlet (Early Access state and routes are
  preserved).
- Player rating/position/chemistry rebalancing and advancing the Chapter 364 cutoff.
- Accounts, backend leaderboards, analytics or online multiplayer.
- A routing rewrite to `play/` directory URLs (new screens use query views on the home
  document, like the existing `?solo=run`).
- Converting the auction "modes" engine into the puzzle engine; both remain, each with
  its own records.
